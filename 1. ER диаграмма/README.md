## 1. Предметная область и пользователи

**Предметная область:** сервис публикации, прослушивания и обсуждения гачи-ремиксов.

**Основной сценарий:** пользователь регистрируется → ремиксер загружает ремикс → трек попадает в ленту, плейлисты и альбомы → другие пользователи ставят лайки, пишут комментарии и проставляют теги → система формирует чарт популярности.

**Пользователи системы:**

| Роль      | Возможности                                           |
| --------- | ----------------------------------------------------- |
| `USER`    | просмотр ленты, лайки, комментарии, плейлисты, теги   |
| `REMIXER` | наследует права USER + записывает и публикует ремиксы |

## 2. Сущности и связи

### Сущности

| Сущность | Первичный ключ | Атрибуты                     |
| -------- | -------------- | ---------------------------- |
| USER     | id             | name, pass, role             |
| REMIXER  | id             | name, age, registered_at     |
| REMIX    | id             | singer, resinger, preview    |
| SINGER   | id             | name, genre, country         |
| PLAYLIST | id             | title, created_at, is_public |
| LENTA    | id             | updated_at                   |
| ALBUM    | id             | title, year                  |
| TAG      | id             | label, timestamp, created_by |
| CHART    | song_id        | place, views                 |
| COMMENT  | id             | text, created_at             |
| LIKE     | id             | created_at                   |

### Связи

| Связь             | Кратность | Смысл               |
| ----------------- | --------- | ------------------- |
| USER → PLAYLIST   | 1:N       | создаёт             |
| USER → LENTA      | 1:1       | имеет               |
| LENTA → REMIX     | 1:N       | включает            |
| PLAYLIST → REMIX  | 1:N       | состоит из          |
| ALBUM → REMIX     | 1:N       | включает            |
| REMIXER → REMIX   | 1:N       | записывает          |
| SINGER → REMIX    | 1:N       | оригинал для        |
| REMIX ↔ TAG       | N:M       | помечен             |
| REMIX → CHART     | 1:1       | занимает            |
| USER → COMMENT    | 1:N       | пишет               |
| COMMENT → REMIX   | N:1       | о                   |
| COMMENT → COMMENT | 1:N       | ответ на (рекурсия) |
| USER → LIKE       | 1:N       | ставит              |
| LIKE → REMIX      | N:1       | получает            |

## 3. Ограничения предметной области

1. **Один к одному для ленты и чарта** — у пользователя ровно одна лента, у ремикса ровно одна запись в чарте.
2. **Ссылочная целостность** — удаление ремикса каскадно удаляет связанные лайки, комментарии и запись чарта.
3. **Отсутствие циклов в комментариях** — комментарий не может быть ответом сам на себя; ответ относится к тому же ремиксу.
4. **Разграничение прав доступа** — только REMIXER публикует ремиксы; `is_public` ограничивает видимость плейлистов.
